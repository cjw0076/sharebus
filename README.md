# ShareBus

ShareBus는 **Avalokita 앱 안에서 에이전트의 메시지·세션·상태를 안정적으로 잇는 내부 통신 계층(ware/wire)**입니다. 이 저장소는 그 계층의 개발자 패키지와 시험용 연결 화면을 제공합니다. 사용자에게 제공할 제품은 여러 에이전트를 품는 하나의 Avalokita 앱이며, 별도의 소비자용 ShareBus 앱을 설정하는 흐름으로 나누지 않습니다.

**[개발자 프리뷰를 공개했습니다.](https://github.com/cjw0076/sharebus/releases/tag/v0.1.0-alpha.1)** `v0.1.0-alpha.1`에서 Python 패키지(wheel), 소스 압축 파일과 체크섬을 받을 수 있습니다. 일반 사용자용 설치 파일과 자연어로 설치·복구를 돕는 전용 안내 대화는 이 릴리스에 포함되지 않습니다.

다음 개발 후보 `0.1.0a2`는 비공개 빌드 준비 중입니다. 이전 R4 소스의 진단 전용 안내 구성은 Windows의 소유 Claude CLI에서 같은 대화 재개·무힌트 회상·정지 상태 진단을 실제 확인했습니다(42/42). 이후 명세·저장소를 수정한 현재 R5 소스는 회귀 155 PASS·subtest 3과 독립 metadata 22·명세 24·시작 24 검사를 통과했습니다. 새 명세에 따른 실제 모델 답변은 추가 시험하지 않았습니다. 안내 화면의 별도 Edge 검증과 [확인 범위·남은 작업](docs/STATUS.md)을 함께 기록했습니다.

## 개발용 연결 화면의 현재 흐름

아래는 내부 통신 계층을 시험하는 현재 소스의 연결 화면 흐름입니다. Avalokita의 첫 실행 자동 조사·비공개 vault·학습 기반 분기·자연어 환경 수정은 별도 증분이며 전체 앱의 첫 실행·선호 품질·복합 업무·설정 복구 인수는 남아 있습니다. 설치부터 앱 연결까지 처음 사용하는 사람의 전체 과정은 아직 검증 중입니다.

1. **개발용 연결 화면에서 작업 폴더를 고릅니다.** 폴더는 마우스로 선택합니다.
2. **사용할 AI 앱을 고르고 ‘연결’을 누릅니다.** 이미 로그인한 앱의 구독을 사용합니다. 앱에서 연결 허용이나 다시 불러오기를 요청하면 안내에 따라 한 번 확인합니다.
3. **열린 작업실에 할 일을 적습니다.** 캐릭터를 누르면 해당 참가자에게 보낼 수 있습니다. 연결된 사람과 답변을 기다리는 사람을 화면에서 확인합니다.

일반 화면에서 연결 번호나 비밀 키를 직접 입력하는 흐름은 사용하지 않습니다. 앱이 발견됐다는 표시와 실제 연결 완료는 구분합니다. 개발 환경과 실행 방법은 [CONTRIBUTING.md](CONTRIBUTING.md)에 있습니다.

## 무엇을 할 수 있나요?

- 같은 컴퓨터의 작업실에서 참가자에게 메시지를 보내고 질문에 답합니다.
- 직접 고른 자료만 공유하고, 대기 중인 일과 결과를 보관합니다.
- 전체 작업이나 특정 참가자의 새 전달을 일시정지합니다. 기록은 남습니다.
- 앱별 대화 연결을 시험할 수 있습니다. 실제로 확인된 범위는 아래와 같습니다.

| 연결 경로 | 개발 기록에서 확인한 범위 | 추가 확인이 필요한 범위 |
| --- | --- | --- |
| Codex | Windows 구독 CLI 대화에서 Claude와 작업·회신을 주고받고, 종료·재시작 뒤 같은 대화 재개와 무힌트 기억 시험을 통과 | 기존 Desktop 대화 연결과 고유 도구 보존 |
| Claude | 같은 Windows 시험에서 작업·회신·최종 결과를 완료하고, 같은 대화 재개와 별도 무힌트 기억 시험을 통과 | 기존 업무 Desktop 대화 연결과 역할·고유 도구 보존 |
| Antigravity | 연결 코드와 합성 시험 | 기존 앱 대화의 실제 전달·결과 회신 |

이는 별도로 소유한 Windows 개발 시험 대화의 확인 범위입니다. 기억 시험은 이전 대화에 저장한 임의 값을 답이나 힌트 없이 물었고, 두 앱이 도구 조회 없이 정확히 답했습니다. 최초의 다른 시험은 질문에 답이 들어 있어 기억 증거에서 제외했습니다. 기존 업무 Desktop 대화, 세 앱 전체 연결, macOS·Linux 실행과 일반 사용자용 설치는 추가 확인 대상입니다. [지원 범위](docs/STATUS.md)에서 시험을 구분해 볼 수 있습니다.

[Windows·macOS·Linux 자동 검사](https://github.com/cjw0076/sharebus/actions/runs/40556549112)에서 소스 검사, 단위 시험, 패키지 빌드와 새 환경의 패키지 설치·CLI·MCP 검사가 통과했습니다. [릴리스 태그 검사](https://github.com/cjw0076/sharebus/actions/runs/40562117068)도 같은 공개 커밋에서 통과했습니다. 첫 실패 기록은 [지원 범위](docs/STATUS.md)에 남겼습니다. 이 결과는 각 운영체제에서 기존 AI 앱 대화나 일반 사용자용 설치 프로그램까지 검증했다는 뜻은 아닙니다.

ShareBus 자체는 유료 모델 API 키를 요구하지 않는 구독 앱 연결을 목표로 합니다. 실제 연결은 해당 앱이 지원하고 검증된 네이티브 경로를 사용해야 합니다. 각 제공자의 로그인, 구독과 사용 한도는 그대로 적용됩니다. ShareBus가 구독을 합치거나 사용량을 무제한으로 만들지는 않습니다.

## 안내 대화는 준비 중입니다

다음 개발 단계에서는 선택한 폴더의 **도움받기**를 눌러 한 입력창에서 질문하고, 나중에 같은 대화를 이어가도록 만듭니다. 업무실이 꺼져 있거나 잠시 멈춰 있어도 도움을 열 수 있고, 창을 여는 것만으로 AI에게 일을 보내거나 업무를 재개하지 않습니다. 처리 여부가 불확실한 요청도 자동으로 다시 보내지 않습니다.

첫 안내 대상은 도구 제한을 실제 확인한 Claude Code 2.1.303입니다. Codex·Antigravity 안내 대화는 같은 검증을 마치기 전까지 지원 대상으로 표시하지 않습니다. 현재 안내 기능의 구현·인수는 진행 중이며, 첫 범위는 설명과 상태 확인입니다. 자연어 요청으로 설정을 바꾸거나 복구하는 기능은 별도 구현·검증이 필요합니다. [안내 대화 명세](docs/GUIDE-SESSION.md)

## 내 정보는 어떻게 다루나요?

작업실 기록과 비공개 연결 정보는 내 컴퓨터에 저장합니다. 선택한 메시지와 자료가 참여 AI 앱에 전달되면 해당 제공자의 처리 정책도 적용됩니다. ShareBus 안내 대화가 전체 대화 이력이나 비밀 키를 요구하는 흐름은 만들지 않습니다.

일시정지와 종료는 새 버스 전달을 멈춥니다. 이미 AI 앱에 접수된 입력은 해당 앱에서 처리 여부를 확인해야 합니다. 같은 OS 계정의 다른 프로그램까지 격리하는 보안 경계는 제공하지 않습니다. [보안 안내](SECURITY.md)
