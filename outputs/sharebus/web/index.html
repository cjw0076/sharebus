    앱 연결 안내

    함께할 앱의 연결 상태를 확인해 보세요.

    ShareBus가 준비된 앱을 열고 자동 참여 설정을 확인하세요. 연결된 대화가 참여하면 작업실에 이름이 나타납니다.
    자동 참여 설정은 이미 준비된 연결을 허용합니다. 앱의 첫 설치나 필요한 승인을 대신하지는 않습니다.
    고급: 기존 대화 직접 등록

    대화 식별자와 연결 방식을 알고 있을 때만 사용하세요. 앱의 이름과 역할을 따로 지정할 수 있습니다.

    대화 UUID와 수신 주소는 서로 다릅니다. 주소를 모르면 비워둘 수 있으며, 실제 수신 전까지 연결 완료로 표시하지 않습니다.

    기존 대화를 등록한 뒤 해당 앱에서 /sharebus로 참여해 수신 경로를 연결해야 합니다. 등록만으로 기존 대화를 자동으로 깨웠다고 판단하지 않습니다.

    버스 관리 세션은 새로운 CLI 대화입니다. 이미 열려 있는 앱 대화와 그 도구 구성을 그대로 가져오지는 않습니다.

    작업실 사용 도움말

    연결된 동료에게 원하는 일을 한 곳에서 말해 보세요.

    1. 함께할 앱을 열어 주세요.

      ShareBus가 준비된 앱의 기존 대화를 사용합니다. 첫 설치나 앱에서 요청한 승인이 끝나야 참여할 수 있어요.

    2. 자동 연결 설정을 확인하세요.

      자동 참여가 허용된 대화는 다음 활동부터 나타납니다. 앱을 발견한 상태와 실제로 연결된 상태는 다르게 표시해요.

    3. 입력창에 하고 싶은 일을 적어 주세요.

      이름을 누르면 그 동료에게 보낼 수 있어요. ‘잠시 멈추기’는 새 작업 전달을 쉬게 합니다. ‘계속하기’를 누르면 다시 허용하며, 확인이 필요한 작업을 자동으로 다시 보내지는 않아요.

    ‘연결 확인 필요’가 계속 보이면 ShareBus에서 작업실을 다시 열고, 해당 앱에 연결 안내나 승인 요청이 있는지 확인해 주세요. 이미 앱에 전달된 작업은 이 화면에서 멈추지 않을 수 있어요.

    고급: 작업실과 공유 방식

    공유한 대화와 자료만 이 작업실의 기록에 남습니다. 같은 OS 계정 안에서 참여자별 쓰기 영역을 나누며, 강한 보안 격리는 아닙니다. 등록·전달·실제 응답은 각각 별도로 확인합니다.

    기존 대화에 연결 코드 전달

    직접 연결을 복구하는 고급 기능입니다. 대상 대화와 역할을 확인한 뒤 아래 내용을 열어 주세요.

    고급: 일회용 연결 코드와 참여 안내

    이 역할을 맡은 기존 대화에만 일회용 코드를 전달해 주세요.

    기존 대화에서 코드를 사용하면 같은 역할로 이어서 참여합니다. 코드는 한 번만 사용할 수 있고 세션 접근 토큰은 이 화면에 표시하지 않습니다.

    자동 연결 꺼짐

    한 번 켜두면 연결 준비가 끝난 기존 대화가 다음 활동부터 이 작업실에 참여합니다.

    기존 대화 연결 상태

    연결 상태를 확인하고 있습니다.

    자동 참여 설정은 준비된 연결을 허용하는 기능입니다. 앱의 첫 설치나 승인을 대신하지 않습니다. 잠시 멈추거나 중지한 역할도 그대로 유지됩니다.

    역할과 모델을 팀에 맞게 바꿀 수 있습니다. 아래 구성은 편집 가능한 개인 시작점입니다.

    설정을 불러오면 편집할 수 있습니다.
