# Source alpha and packaged-app acceptance

Every claim needs evidence from the selected source. Developer package publication and distribution of a working consumer app have separate acceptance. Updated 2026-10-28: [prerelease `v0.1.0-alpha.1`](https://github.com/cjw0076/sharebus/releases/tag/v0.1.0-alpha.1) is public at `9f86cb1e3680651bc69f8346a77f6ea8ac88c645`, with wheel, source archive and checksums. No end-user installer or Windows runtime bundle has been published. The guide increment is not included in that release.

The intended packaged flow is **open ShareBus → choose folder/apps and Connect → type work in the console**. **Help** should open the same dedicated support conversation without changing the business room or starting a model turn. Initial explanation/diagnosis must not be described as completed configuration repair. The guide increment is under implementation and acceptance; it does not change the scope of the published developer prerelease. Developer commands belong in `CONTRIBUTING.md`.
